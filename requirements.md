# Web Drive

A digital storage system similar to that of GoogleDrive and OneDrive.

## User Experience

- [x] User can register for an account and log in using email
- [x] User can upload files to store from their device and it stores in DB
- [ ] User can search for files by their name
- [x] User can delete files from their drive
- [x] User can download files from their drive

### Extra Features

- [x] User can see recently viewed / accessed files
- [ ] User can filter files by their extension
- [x] User can preview files when they click on them
- [x] User can share files with other users

## Tech Stack

- Next.js
- React
- Node.js
- Appwrite for database and authentication
